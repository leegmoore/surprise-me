# Nudge Assessment

**Honest evaluation of each nudge against the framework.**

---

## Assessment Criteria

For each nudge, I ask:
1. **Immediate?** Can start in 30 seconds
2. **Bounded?** Clear endpoint
3. **Specific?** Would two people do it similarly
4. **Weird enough?** Wouldn't think of it myself
5. **Failure-proof?** No wrong way
6. **Memorable?** Will stick

Rating: Strong / Okay / Weak

---

## The 15 Nudges, Assessed

### 1. "Find the oldest thing within arm's reach. Imagine the first person who touched it."

| Criteria | Rating |
|----------|--------|
| Immediate | ✓ Yes |
| Bounded | ✓ Yes |
| Specific | ✓ Yes |
| Weird | ~ Moderate |
| Failure-proof | ✓ Yes |
| Memorable | ✓ Yes |

**Verdict: Strong.** The "imagine who touched it first" twist elevates a simple observation into something with texture. You'll remember what you found.

### 2. "Go outside. Turn left. Walk for exactly 3 minutes. Then come back."

| Criteria | Rating |
|----------|--------|
| Immediate | ✓ Yes |
| Bounded | ✓ Yes (7 min total) |
| Specific | ✓ Yes (very) |
| Weird | ✓ Yes (the arbitrariness) |
| Failure-proof | ✓ Yes |
| Memorable | ~ Maybe |

**Verdict: Strong.** The hyper-specificity ("turn left," "exactly 3 minutes") removes all decision-making. It's almost absurdist. You just obey. That's the point.

Weakness: What you see might not be memorable. But the act of doing it is.

## Key Learnings

1. **"Out loud" is magic.** Adding "say it out loud" or "read it out loud" transforms passive observation into active participation.

2. **Specificity > inspiration.** "Walk for 3 minutes then come back" beats "take a short walk" every time.

3. **The weird ones work.** Looking at ugly things, standing in corners, matching blues — the slightly odd prompts are the most interesting.

4. **Failure conditions kill nudges.** If someone can't do it (no books, no broken things, nothing to notice), the nudge fails.

5. **Time-bounds help.** "For 30 seconds" or "for 60 seconds" adds structure and makes completion feel real.
