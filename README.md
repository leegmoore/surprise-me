# nudge

A micro-adventure generator.

## What it does

Gives you a small, specific, slightly weird thing to do. Right now.

## Usage

```
node src/index.js
```

Or, if installed globally:

```
nudge
```

## Example output

```
  Find something blue. Then find something that's almost the same blue, but not quite.

  2-3 min · anywhere
```

## Why

Sometimes you have time but no idea what to do with it. Nudge decides for you.
